Про проєкт

Навчальний вебзастосунок для лабораторної роботи 06 «Інтеграція клієнтської частини з API та обробка помилок». Серверна частина — Flask і SQLite, клієнтська — HTML, CSS і JavaScript без фреймворків.

Ендпоінти API

МетодАдресаПризначення
GET/api/healthперевірка роботи сервера
GET/api/metaкатегорії, сортування, обмеження полів
GET/api/productsсписок товарів (пошук, фільтр, сортування)
GET/api/products/<id>один товар
POST/api/productsстворення товару
PUT/api/products/<id>оновлення товару
DELETE/api/products/<id>видалення товару

Склад команди

Роботу виконано одноосібно: серверну частину, клієнтську частину, тестування і звіт зробив автор репозиторію.
