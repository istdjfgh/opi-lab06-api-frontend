«Кубик» — навчальний магазин на Flask і SQLite. Каталог зберігається в базі, а сторінка «Демо API» працює з ним через REST API за допомогою fetch(): показує список, додає, редагує й видаляє товари без перезавантаження сторінки.

Відкрити демо API Сирий JSON /api/products

⚡ Асинхронно

Запити виконуються через async/await, сторінка не «зависає» під час очікування відповіді.

🛡️ Надійно

Перевірка response.ok, тайм-аут запиту, зрозумілі повідомлення, якщо сервер недоступний.

✅ Валідація

Однакові правила в браузері й на сервері: обмеження клієнт отримує з GET /api/meta.
